# First exercise

Use a test business, a test recipient and a paused campaign only.

1. Create `BUSINESS-TRUTH.md` with one offer, customer, geography, customer value and verified outcome.
2. Run both read-only preflights.
3. Complete `META-TRUTH.md` without secrets.
4. Write one end-to-end funnel in `META-GROWTH-PLAN.md`.
5. Create a dry-run campaign receipt.
6. Create a dry-run WhatsApp template-test receipt.
7. Review the account, budget, recipient ending, message purpose and rollback.
8. Only then decide whether to authorize the paused Meta build and owned-number test.

The exercise passes when the objects remain paused, the test recipient is owned or explicitly authorized, webhook signatures validate, delivery is distinguished from acceptance, and the funnel report names its unknowns.
